# PM3: OSINT Investigation with Maltego

## Objective
Explore domain relationships using Maltego's graphical OSINT investigation tools.

## Tools
- Maltego Graph Desktop
- Kali Linux

## Activities
- Installed and configured Maltego.
- Created a domain entity for `example.com`.
- Performed DNS-related transforms.
- Executed a publicly indexed email-discovery transform.
- Visualized relationships between discovered entities.

## Results
The email-discovery transform returned 17 entities. These results were not independently verified as active email accounts.

## Scope
This was a practice investigation using the reserved demonstration domain `example.com`.

Screenshots of Maltego installation, domain entity creation, DNS transforms, and email discovery are included in this folder.
