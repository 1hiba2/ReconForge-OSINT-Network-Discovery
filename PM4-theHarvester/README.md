# PM4: OSINT Reconnaissance with theHarvester

## Objective
Practice passive information gathering using theHarvester on Kali Linux.

## Tools
- Kali Linux
- theHarvester 4.11.1

## Activities
- Reviewed theHarvester's command options.
- Attempted the Baidu source, which was unsupported by the installed version.
- Used crtsh as an alternative source.
- Executed a multi-source search using `-b all`.
- Documented API key errors and source limitations.

## Results
The exercises used `example.com` as a demonstration target. The multi-source search returned hostnames, but these results were not independently verified.

Screenshots documenting the commands, results, and limitations are included in this folder.
